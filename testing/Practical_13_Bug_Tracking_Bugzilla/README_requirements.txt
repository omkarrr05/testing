PRACTICAL No. 13 - Bug Tracking and Defect Lifecycle Management
======================================================================

TOOLS USED
----------
  * Mozilla Bugzilla (https://bugzilla.mozilla.org) - web based bug tracker
  * Mozilla Firefox
  * Google Chrome
  * Google Search

REQUIREMENTS
------------
  * HTML form : NOT needed (uses the public Bugzilla website)
  * Excel data : NOT needed
  * Java code  : NOT needed
  * Other      : an e-mail address to create a free Bugzilla account

FILES IN THIS PRACTICAL
-----------------------

STEPS / HOW TO RUN
------------------
1. Search "Mozilla Bugzilla" on Google and open bugzilla.mozilla.org.
2. Create an account: "New Account" -> e-mail -> confirm through the mail link -> set name and password.
3. Using FIREFOX: type a defect keyword (e.g. "login", "crash") in the Quick Search box, open a bug and analyse every field:
     Bug ID, Summary, Product / Component, Status (UNCONFIRMED -> NEW -> ASSIGNED -> RESOLVED -> VERIFIED -> CLOSED / REOPENED),
     Resolution (FIXED, DUPLICATE, INVALID, WONTFIX, WORKSFORME), Severity, Priority, Version, Platform / OS, Assignee, Reporter,
     Description (steps to reproduce / expected / actual), Comments and Attachments, History, See Also / Depends on / Blocks.
4. Repeat the same search and analysis in GOOGLE CHROME and note the differences (none expected - it is a website).
5. Take screenshots of: search page, account creation, bug list, bug detail page.
Defect life cycle to describe in the write-up: New -> Assigned -> Open -> Fixed -> Retest -> Verified -> Closed (or Reopened / Rejected / Deferred).
